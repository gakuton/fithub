## 対象ファイルの特定

引数が指定されていれば $ARGUMENTS を対象にする。
省略された場合は以下のgit diffの結果から変更されたUIファイルを対象とする：

```
!`git diff --name-only HEAD | grep -E '\.(tsx|jsx|css)$' | head -30`
```

## チェック項目

以下のルールを対象ファイルごとに確認し、違反があればファイル名・行番号・問題点・修正案を日本語で報告する。違反がなければ「問題なし」と簡潔に伝える。

### カラー
- `gray-*` / `slate-*` / `zinc-*` などのグレー系クラスを使っていないか（FitHubのニュートラルはhue 277ベースのカスタムトークンのみ）
- セマンティック色が正しいか：体脂肪率 → `text-orange-500`、骨格筋 → `text-green-500`、有酸素 → `text-sky-500`
- `--primary` / `--muted` / `--border` などのCSS変数を使っているか（ハードコードした色は原則NG）

### 形状・シャドウ
- カードの角丸は `rounded-2xl` を使っているか（`rounded-3xl` や `rounded-full` のカードはNG）
- ボタン・入力欄は `rounded-lg` または `rounded-xl` を使っているか
- シャドウは `shadow-sm` のみか（`shadow-md` 以上は原則NG）

### アイコン
- `lucide-react` 以外のアイコンライブラリを使っていないか
- デフォルトの `strokeWidth` は 1.8 か（アクティブ状態は 2.5）
- アイコンの代わりに絵文字を使っていないか

### コピーライティング
- テキストはすべて日本語か（UI文言に英語を混ぜていないか）
- 感嘆符（！）を過剰に使っていないか
- 二人称（あなた・君）を使っていないか

### その他
- 画像・グラデーション・背景パターンを使っていないか（ロゴは例外）
- `pb-20` でBottomNav分のパディングが確保されているか（全画面ページ）
- タップ領域は `min-h-[44px]` 以上か

最後に違反の件数サマリーを出す。
