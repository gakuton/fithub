## チェック項目を順番に実行する

### 1. TypeScript型チェック
```bash
npx tsc --noEmit
```
エラーがあれば報告して修正を促す。エラーがなければ「✅ 型チェック OK」と伝える。

### 2. ビルド確認
```bash
npm run build
```
ビルドエラーがあれば報告して修正を促す。成功すれば「✅ ビルド OK」と伝える。

### 3. 環境変数チェック
`.env.local` に以下が含まれているか確認する（値は表示しない）：
- `ANTHROPIC_API_KEY`
- `TURSO_DATABASE_URL`
- `TURSO_AUTH_TOKEN`

また、Vercelの本番環境にも同じ変数が必要であることを案内する。

### 4. 未コミットの変更チェック
git statusを確認し、コミットし忘れているファイルがあれば警告する。

### 5. マイグレーションチェック
`drizzle/migrations/` の最新ファイルと `lib/db/schema.ts` の変更日時を比較する。
スキーマを変更してマイグレーションを生成していない可能性がある場合は警告する。

```
!`ls -lt drizzle/migrations/ | head -5`
```
