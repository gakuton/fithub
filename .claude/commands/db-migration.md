## 現在のスキーマ変更の確認

```
!`git diff lib/db/schema.ts`
```

## 手順

以下を順番に実行する。

### 1. 変更内容の確認
上記のgit diffを読み、どのテーブル・カラムが追加・変更・削除されたかを日本語でサマリーする。
変更がない場合は「スキーマに変更はありません」と伝えて終了する。

### 2. マイグレーションの生成
以下のコマンドでマイグレーションファイルを生成する（実行前に確認を取ること）：

```bash
npx drizzle-kit generate
```

生成されたファイルのパスと内容を確認して報告する。

### 3. ローカルDBへの適用
以下のコマンドでローカルのSQLiteに適用する（実行前に確認を取ること）：

```bash
npx drizzle-kit migrate
```

### 4. 完了確認
- マイグレーションファイルが `drizzle/migrations/` に追加されたか確認する
- `lib/db/schema.ts` と合わせてgit addするよう案内する

### 注意事項
- 本番DBへの適用はVercelのデプロイ時に自動では行われない。Tursoの本番DBに対して別途 `npx drizzle-kit migrate` を実行する必要がある（本番環境変数が必要）
- カラムの削除・型変更はデータ消失のリスクがあるため、影響範囲を必ず確認する
